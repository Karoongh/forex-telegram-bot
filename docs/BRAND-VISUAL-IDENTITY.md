# Forex Trader Visual Identity & Image Generation Guidelines

> Living visual-brand specification for the fictional recurring trader character used across the Forex project.
>
> This document is the single source of truth for the character's visual identity, photography rules, lifestyle representation, lighting, shadows, natural behavior, and reusable image-generation prompts.

## 1. Purpose

The project needs a consistent fictional trader persona for social media, educational content, market-analysis posts, Telegram content, and other brand-facing materials.

The goal is **not** to create a stereotypical "forex millionaire" image.

The intended perception is:

> Successful, knowledgeable, disciplined, financially comfortable, and trustworthy — while still looking like a normal real person.

The visual identity must support credibility through consistency, professionalism, realism, transparency, and relatable behavior rather than exaggerated displays of wealth.

### Important distinction

Persona decisions in this document are **brand-design choices**, not factual claims that a particular gender, age, ethnicity, location, body type, or appearance objectively makes a financial professional more trustworthy.

Trust should ultimately be supported by the service's real behavior, transparency, risk disclosure, performance reporting, security practices, and customer experience.

## 2. Character Identity

### Character ID

**FX-TRADER-01**

This identifier should be used internally whenever a recurring character is generated.

### Core appearance

- Fictional male
- Approximately 32 years old
- Middle Eastern / Mediterranean appearance
- Light olive skin
- Dark brown eyes
- Thick dark brown hair
- Naturally styled hair with a subtle side part
- Short, well-groomed dark beard and mustache
- Natural eyebrows
- Straight, medium-sized nose
- Defined but natural jawline
- Realistic facial asymmetry
- Realistic skin texture and pores
- Approximately 180 cm
- Healthy, moderately athletic build
- Naturally broad shoulders
- Normal human proportions

He should look like a successful professional in his early 30s, **not like a fashion model or fitness influencer**.

### Identity consistency

Future images must preserve:

- Same recognizable face
- Same approximate age
- Same hairstyle
- Same beard style
- Same skin tone
- Same eye color
- Same body proportions
- Same overall physical identity

A reference image should be maintained and supplied to image-generation tools whenever possible.
